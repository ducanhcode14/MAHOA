## 📚 Giới thiệu Repository
Repository này chứa toàn bộ mã nguồn, tài liệu thực hành và các bài lab chuyên đề về **Mã hóa (Cryptography) & An toàn bảo mật thông tin**, bao gồm:
1. **Mã hóa cổ điển (Classical Ciphers):** Caesar, Vigenère, Rail Fence, Playfair, Hoán vị cột (Transposition), Autokey.
2. **Kỹ thuật thám mã / Phân tích mật mã (Cryptanalysis):** Tấn công vét cạn (Brute-force), Phân tích tần suất chữ cái (Frequency Analysis), Tấn công biết trước bản rõ (Known Plaintext Attack).
3. **Ứng dụng giao diện (GUI):** Xây dựng ứng dụng Java Swing trực quan, tích hợp quản lý lịch sử mã hóa lưu trữ trên hệ quản trị cơ sở dữ liệu Microsoft SQL Server.
